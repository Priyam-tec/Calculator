# Calculator
The "Simple Calculator" is a beginner-friendly project designed to help new programmers understand the basics of Java programming. It demonstrates the use of fundamental programming concepts such as input/output operations, conditional statements, loops (if needed), and arithmetic operations.

The project allows the user to perform basic mathematical calculations such as:

Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
By entering two numbers and selecting an operation, the program calculates and displays the result.
